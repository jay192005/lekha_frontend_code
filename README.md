# Lekha Frontend

Frontend application for the Lekha Rent Agreement Analyzer.

## Features

- User authentication (login/register)
- Document upload and analysis
- Analysis history viewing
- Interactive UI for rent agreement review

## Files

- `index.html` - Main landing page
- `analyzer.html` - Document analysis interface
- `history.html` - Analysis history page
- `script.js` - Main JavaScript logic
- `analyzer.js` - Analysis page logic
- `history.js` - History page logic
- `style.css` - Main stylesheet
- `analyzer.css` - Analysis page styles

## Setup

1. Update the API endpoint in the JavaScript files to point to your backend URL
2. Deploy to your hosting platform (Vercel, Netlify, etc.)
